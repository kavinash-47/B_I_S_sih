## Two real bugs found and fixed during interactive testing (before formal test suite existed)

1. **`bm25_search.py` / `semantic_search.py`**: the SQL `SELECT` omitted `year` and
   `source_url`, so every search result showed `year: null`. Fixed by adding both
   columns to the query.
2. **`brand_checker.py`**: matched brand name "ACC" as a substring inside the
   unrelated word "accepted". Fixed with `\b` word-boundary regex — confirmed by
   `test_word_boundary_no_false_positive_substring`.
3. **Data entry**: `data/standards.csv` had "2013" typed into the `part` column
   for IS 8112 and IS 12269 (should have been empty — year already captures it).
   Fixed in the source CSV and reloaded.
